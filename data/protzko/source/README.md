# Protzko 2019 OSF source

This directory contains the private OSF data materials linked from project
`xjwth`. Raw files in this directory are excluded from Git. The tracked
`manifest.csv` fixes the expected filenames, byte counts, and SHA-256 hashes.

The received files are:

- `StanfordProspectwithinsubjects2x2.dta`
- `StanfordProspectwithinsubjects2x2REPLICATE.dta`
- `UCSBreplicateexplicitbalance.dta`
- `study2prospecttheorycombinedanon.dta`

The November 2019 manuscript, analysis scripts, codebook, questionnaires, and
preregistration have not yet been received. Those files are still needed to
verify the reported sample rules and reconstruct the original analysis rather
than merely infer it from the data exports.
